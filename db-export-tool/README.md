# 数据库导出工具 v2.0

企业级数据库数据导出工具，支持MySQL、达梦数据库，提供灵活的数据导出能力。

## 🌟 功能亮点

### 核心功能
- **多种导出模式**：支持自定义表名、表勾选、自定义SQL三种导出方式
- **强大数据过滤**：支持时间范围过滤和字段条件过滤，可组合使用
- **多格式导出**：同时支持Excel(.xlsx)和SQL(.sql)格式导出
- **任务模板**：保存常用配置为模板，支持批量导入导出模板
- **实时进度**：导出过程实时显示进度和日志
- **历史记录**：查看和下载历史导出文件

### 技术特性
- **高性能**：使用HikariCP连接池，支持多线程并发导出
- **低内存**：流式读写，大数据量下内存占用低
- **安全**：数据库连接只读模式，SQL注入防护
- **易用**：简洁的Web界面，小白也能轻松使用

## 📦 环境要求

- **JDK 8** 或更高版本
- **Maven 3.6+** (用于编译，可选)
- **MySQL 5.7+** 或 **达梦 7/8**
- **现代浏览器** (Chrome、Firefox、Edge等)

## 🚀 快速开始

### 方式一：使用编译好的JAR

1. 下载 `db-export-tool.jar`
2. 创建必要的目录：
   ```bash
   mkdir -p exports templates logs temp
   ```
3. 直接运行：
   ```bash
   java -jar db-export-tool.jar
   ```
4. 打开浏览器访问：http://localhost:8080
5. 使用默认账号登录：`admin` / `123456`

### 方式二：从源码编译

#### Windows系统
```bash
# 1. 进入项目目录
cd db-export-tool

# 2. 执行安装脚本
scripts\install.bat

# 3. 启动应用
scripts\start.bat
```

#### Linux/Mac系统
```bash
# 1. 进入项目目录
cd db-export-tool

# 2. 给脚本添加执行权限
chmod +x scripts/*.sh

# 3. 执行安装脚本
scripts/install.sh

# 4. 启动应用
scripts/start.sh
```

## 📖 使用说明

### 1. 登录系统

打开浏览器访问 http://localhost:8080，使用默认账号登录：
- 用户名：`admin`
- 密码：`123456`

> 提示：可以在配置文件中修改默认账号密码

### 2. 连接数据库

1. 在首页填写数据库连接信息：
   - **数据库类型**：选择 MySQL 或 达梦
   - **主机地址**：数据库服务器IP或域名
   - **端口**：数据库端口（MySQL默认3306，达梦默认5236）
   - **数据库名**：要连接的数据库名称
   - **用户名**：数据库账号
   - **密码**：数据库密码

2. 点击「测试连接」验证配置是否正确
3. 点击「连接数据库」建立连接

### 3. 选择导出方式

#### 方式A：自定义表名
- 在文本框中输入要导出的表名
- 支持逗号、顿号、换行分隔
- 例如：`table1, table2, table3`

#### 方式B：表勾选
- 点击「选择数据表」按钮
- 在弹窗中勾选要导出的表
- 支持搜索、全选、反选
- 点击「确定」完成选择

#### 方式C：自定义SQL
- 输入SELECT语句
- 每行一条SQL
- 例如：
  ```sql
  SELECT * FROM table1 WHERE status = 1
  SELECT id, name FROM table2
  ```

### 4. 配置数据过滤

#### 时间过滤
1. 勾选「启用时间过滤」
2. 填写时间字段名（支持多个，逗号分隔）
3. 选择开始日期和结束日期
4. 系统会自动查找表中匹配的时间字段进行过滤

#### 字段过滤
1. 勾选「启用字段过滤」
2. 填写字段名
3. 选择过滤方式：
   - **等于**：精确匹配单个值
   - **包含**：匹配多个值（逗号分隔）
   - **范围**：匹配数值范围（用-分隔，如：100-200）
4. 填写参数值

### 5. 配置导出格式

- **Excel**：导出为Excel文件，每个表一个Sheet
- **SQL**：导出为SQL INSERT语句
- 可以同时选择两种格式，会打包到同一个ZIP文件中
- 最大并发连接数：控制同时连接数据库的线程数（1-10）

### 6. 开始导出

点击「开始导出」按钮，系统会显示：
- 整体进度条
- 当前处理的表
- 已完成/总表数
- 总数据量
- 已用时间和预计剩余时间
- 实时操作日志

导出完成后，可以点击「下载」按钮获取导出文件。

### 7. 使用模板

#### 保存模板
1. 配置好导出参数后
2. 点击「保存为模板」
3. 填写模板名称和描述
4. 点击「保存」

#### 加载模板
1. 点击「加载模板」
2. 在弹窗中选择要使用的模板
3. 配置会自动填充到界面

#### 模板管理
- 切换到「模板管理」页面
- 可以查看所有模板
- 支持批量导出模板为ZIP
- 支持从ZIP导入模板
- 可以删除不需要的模板

### 8. 查看导出历史

切换到「导出记录」页面，可以：
- 查看所有历史导出文件
- 下载已有的导出文件
- 删除不需要的文件

## ⚙️ 配置说明

配置文件位于 `src/main/resources/application.yml`（或在jar包同级目录创建）：

```yaml
server:
  port: 8080                    # 服务端口

app:
  export-path: ./exports        # 导出文件存储目录
  temp-path: ./temp             # 临时文件目录
  template-path: ./templates    # 模板存储目录
  batch-size: 1000              # 批量写入大小
  fetch-size: 1000              # 数据库查询获取大小

security:
  default:
    username: admin             # 默认用户名
    password: 123456            # 默认密码
```

## 🎯 常见问题

### Q: 导出大数据量时内存不足怎么办？
A: 本工具使用流式读写，对内存占用很低。如果仍然遇到问题，可以：
- 降低「最大并发连接数」
- 减少同时导出的表数量
- 增加JVM内存：`java -Xmx4G -jar db-export-tool.jar`

### Q: 如何修改默认账号密码？
A: 在配置文件中修改 `security.default.username` 和 `security.default.password`，重启服务生效。

### Q: 支持哪些数据库？
A: 当前支持 MySQL 和 达梦数据库。达梦需要额外添加JDBC驱动到classpath。

### Q: 导出的SQL文件格式是什么？
A: 使用批量INSERT格式，默认1000条一批，方便导入恢复。

### Q: 如何添加达梦数据库支持？
A: 将达梦JDBC驱动（DmJdbcDriver18.jar）放到项目的 lib/ 目录，然后修改 pom.xml 添加依赖。

## 🔒 安全说明

- 所有数据库连接强制使用只读模式
- 自定义SQL只允许SELECT语句
- 输入参数进行严格的SQL注入防护
- Session超时自动登出（默认30分钟）
- 建议生产环境修改默认密码

## 📈 性能优化建议

1. **合理设置并发数**：根据数据库性能调整，通常3-5个最合适
2. **分批导出**：数据量很大时，建议按时间或其他条件分批导出
3. **使用合适的格式**：Excel适合查看，SQL适合数据恢复
4. **定期清理**：及时删除不需要的导出文件释放空间
