# 数据库导出工具 V2.0 - Spark Brief

## 项目概述

面向企业内网的数据库数据导出系统，解决生产库到开发/测试环境的数据同步需求。

## 核心价值

- **高效**：多线程并行导出 + 流式读写，支持百万级数据导出
- **灵活**：3种导出模式 + 2种过滤策略 + 多格式输出
- **安全**：只读连接 + SQL注入防护 + 会话安全
- **易用**：任务模板管理 + 直观UI + 一键操作

## 功能范围

### 必须实现（P0）

1. **用户认证**：登录/登出，默认账号 admin/123456，30分钟超时
2. **数据库连接**：支持达梦DM + MySQL + 自定义，连接测试，连接池监控
3. **数据导出 - 自定义表名**：手动输入表名，支持顿号/逗号/换行分隔
4. **数据导出 - 表勾选**：从数据库表列表选择，搜索/全选/反选
5. **数据导出 - 自定义SQL**：输入SELECT语句，SQL校验
6. **数据过滤 - 时间范围**：字段名+日期范围，兜底全量导出
7. **数据过滤 - 自定义字段**：等于/包含/范围三种方式
8. **数据过滤 - 策略组合**：时间+字段同时启用
9. **导出格式**：Excel(.xlsx) + INSERT SQL(.sql) + 同时导出
10. **导出配置**：最大并发连接数(1-10)，导出格式选择
11. **导出进度**：进度条、实时日志(INFO/SUCCESS/WARNING/ERROR)、取消导出
12. **导出完成**：统计弹窗、文件下载
13. **任务模板管理**：CRUD、批量导入导出ZIP
14. **历史导出记录**：文件列表、重新下载、批量删除
15. **UI主题**：浅色/深色主题切换，响应式布局

### 技术栈

- 后端：Spring Boot 2.7.x + HikariCP + Apache POI
- 前端：原生HTML/CSS/JS（内网离线运行）
- 数据库：达梦DM + MySQL
- 构建工具：Maven

## 验收标准

1. 所有P0功能完备无缺失
2. UI严格遵循设计方案，支持深浅主题切换
3. 10万行单表导出 < 2分钟，内存峰值 < 512MB
4. 10表并行导出无明显卡顿
5. 连接池导出完成后活跃连接归零
6. SQL注入防护有效，仅允许SELECT
7. 部署文档完善，可独立安装使用

## 不做

- 定时调度（扩展功能，P1-P3）
- 数据脱敏（扩展功能）
- 多数据库同时连接
- 移动端适配
- 云存储集成

## 复杂度评估

**中等偏高**：后端Spring Boot + JDBC + 多线程 + 流式处理，前端原生JS实现SPA式交互，需要精心设计异步导出和实时进度推送。

## 风险点

1. 达梦数据库驱动兼容性 - 需确保DM驱动正确加载
2. 大数据量内存控制 - SXSSFWorkbook流式写入需严格验证
3. 并发导出连接管理 - Semaphore控制需防止连接泄漏
