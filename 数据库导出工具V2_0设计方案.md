# 数据库导出工具 V2.0 设计方案

## 版本：V2.0
## 日期：2025年5月

---

## 一、产品定位

### 1.1 产品概述

数据库导出工具是一款面向企业内网的数据库数据导出系统，专注于解决生产库到开发/测试环境的数据同步需求。系统提供灵活的数据导出能力和可复用的任务模板管理，支持高效、安全地导出大规模数据。

### 1.2 核心功能

| 功能模块 | 功能描述 |
|---------|---------|
| 数据导出 | 支持多种导出模式、多策略数据过滤、多格式输出 |
| 任务模板 | 支持配置保存、模板管理、批量导入导出 |

### 1.3 目标用户

- 数据库管理员
- 开发人员
- 测试人员

## 二、功能模块设计

### 2.1 数据导出模块

#### 2.1.1 导出模式

| 模式 | 描述 |
|------|------|
| 自定义表名导出 | 手动输入表名列表，支持顿号、逗号、换行分隔 |
| 表勾选导出 | 从数据库表列表中选择，支持搜索、全选 |
| 自定义SQL导出 | 输入SELECT语句，每行一条，Sheet名自动提取表名 |

#### 2.1.2 数据过滤策略

**策略一：时间范围过滤**

| 配置项 | 说明 |
|--------|------|
| 字段名 | 支持多个字段（顿号分隔），如 `DATE、DATA_TIME` |
| 开始日期 | yyyy-MM-dd 格式 |
| 结束日期 | yyyy-MM-dd 格式 |
| 兜底逻辑 | 表中无匹配字段时，导出该表全量数据 |

生成的SQL条件：
```sql
WHERE DATE >= '2025-01-01' AND DATE <= '2025-01-31'
```

**策略二：自定义字段过滤**

| 配置项 | 说明 |
|--------|------|
| 字段名 | 指定过滤字段，如 `CASE_ID`、`STATUS`、`TYPE` |
| 过滤方式 | 等于 / 包含 / 范围 |
| 参数值 | 根据过滤方式输入对应值 |
| 兜底逻辑 | 表中无匹配字段时，导出该表全量数据 |

过滤方式详解：

| 方式 | 参数格式 | 示例 | 生成SQL |
|------|---------|------|---------|
| 等于 | 单个值 | `111` | `WHERE CASE_ID = '111'` |
| 包含 | 逗号分隔多个值 | `'111','222','333'` | `WHERE CASE_ID IN ('111','222','333')` |
| 范围 | 数值范围 | `100-200` | `WHERE CASE_ID >= 100 AND CASE_ID <= 200` |

**策略组合**

两种过滤策略可同时启用，生成组合条件：
```sql
SELECT * FROM TABLE 
WHERE DATE >= '2025-01-01' 
  AND DATE <= '2025-01-31'
  AND CASE_ID IN ('111','222','333')
```

优先级：先应用时间过滤，再应用字段过滤。任一策略无匹配时，该策略不生效。

#### 2.1.3 导出格式

| 格式 | 说明 |
|------|------|
| Excel (.xlsx) | 单文件多Sheet，每个表一个Sheet |
| INSERT SQL (.sql) | 批量插入格式，默认1000条/批 |
| 同时导出 | 同时生成两种格式，打包到同一压缩包 |

SQL批量插入格式：
```sql
-- TABLE_NAME 表数据 (共 5,000 条)
INSERT ALL
INTO TABLE_NAME (ID, NAME, DATE) VALUES ('001', '测试1', '2025-01-01')
INTO TABLE_NAME (ID, NAME, DATE) VALUES ('002', '测试2', '2025-01-02')
...
SELECT 1 FROM DUAL;
```

#### 2.1.4 导出配置

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 最大并发连接数 | 5 | 控制并行导出线程数，范围1-10 |
| 导出格式 | Excel+SQL | 可选择单一格式或同时导出 |

#### 2.1.5 导出结果

| 项目 | 格式/说明 |
|------|----------|
| 压缩包命名 | `{数据库名}_{yyyyMMddHHmmss}.zip` |
| 文件下载 | 前端点击下载，支持断点续传 |
| 导出记录 | 历史导出文件列表，支持重新下载 |

### 2.2 任务模板模块

#### 2.2.1 模板管理功能

| 功能 | 描述 |
|------|------|
| 保存模板 | 将当前导出配置保存为模板 |
| 加载模板 | 选择模板一键加载配置到界面 |
| 删除模板 | 删除不需要的模板 |
| 模板列表 | 分页展示所有模板，显示名称、描述、创建时间 |

#### 2.2.2 模板导入导出

| 功能 | 描述 |
|------|------|
| 批量导出 | 多选模板打包为ZIP文件下载 |
| 批量导入 | 上传ZIP文件批量导入模板 |

```json
  "id": 1,

  "createTime": "2025-05-01T10:00:00",
  "updateTime": "2025-05-01T10:00:00"
}
```

### 2.3 数据库连接模块

#### 2.3.1 支持的数据库

| 数据库类型 | 驱动类名 | 默认端口 |
|-----------|---------|---------|
| 达梦 DM | dm.jdbc.driver.DmDriver | 5236 |
| MySQL | com.mysql.cj.jdbc.Driver | 3306 |
| 自定义 | 用户指定 | 用户指定 |

#### 2.3.2 连接配置

| 配置项 | 说明 |
|--------|------|
| 数据库类型 | 下拉选择：达梦、MySQL、自定义 |
| 主机地址 | 数据库服务器IP或域名 |
| 端口 | 数据库服务端口 |
| 数据库名 | 连接的数据库名称 |
| 用户名 | 数据库账号 |
| 密码 | 数据库密码 |

#### 2.3.3 连接管理

| 功能 | 描述 |
|------|------|
| 测试连接 | 验证连接配置是否正确 |
| 连接数据库 | 建立连接并加载表列表 |
| 连接池监控 | 实时显示活跃/空闲/总连接数 |

### 2.4 系统功能

#### 2.4.1 用户认证

| 功能 | 描述 |
|------|------|
| 登录 | 账号密码验证 |
| 默认账号 | admin / 123456（可在配置文件中修改） |
| 会话超时 | 30分钟无操作自动登出 |

#### 2.4.2 导出进度

| 展示项 | 说明 |
|--------|------|
| 进度条 | 百分比进度展示 |
| 当前表 | 正在处理的表名及数据条数 |
| 整体进度 | 已完成表数/总表数 |
| 数据统计 | 总数据条数 |
| 时间统计 | 已用时、预计剩余时间 |
| 实时日志 | 分级日志（INFO/SUCCESS/WARNING/ERROR） |

## 五、性能设计

### 5.1 多线程并行导出

- 使用 `ThreadPoolTaskExecutor` 管理导出线程池
- 核心线程数：4，最大线程数：8
- 使用 `Semaphore` 控制并发数据库连接数
- 使用 `CountDownLatch` 等待所有任务完成

### 5.2 流式读取

- 设置 `ResultSet.TYPE_FORWARD_ONLY` 和 `setFetchSize(1000)`
- 避免一次性加载大量数据到内存

### 5.3 分批写入

- Excel使用 `SXSSFWorkbook`，内存中只保留100行
- SQL使用批量INSERT，每1000条一批
- 定期刷出临时文件，触发GC

### 5.4 连接池管理

- HikariCP连接池，最大连接数可配置
- 强制只读模式：`conn.setReadOnly(true)`
- 连接泄漏检测：60秒阈值
- 任务结束强制关闭所有连接

## 六、安全设计

### 6.1 数据库只读

- 所有数据库连接强制设置为只读模式
- 禁止执行任何修改类SQL语句

### 6.2 SQL注入防护

- 白名单机制：仅允许SELECT相关关键字
- 黑名单拦截：禁止INSERT/UPDATE/DELETE/DROP等关键字
- 注释去除：防止通过注释绕过检测
- 分号拦截：禁止多语句执行

### 6.3 会话安全

- Session超时：30分钟无操作自动登出
- 登录拦截：所有API接口需登录后方可访问
- 密码脱敏：前端不显示完整密码

### 6.4 异常容错

- 单表导出失败自动跳过，不影响其他表
- 详细错误日志记录
- 导出结果汇总：成功数、失败数、警告信息
